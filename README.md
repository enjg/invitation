# 💌 活动邀请函

沉浸式H5活动邀请函

## 技术栈
- 原生 HTML5 + CSS3 + JavaScript
- Python HTTP Server

## 运行
```bash
python3 server.py    # http://localhost:8888
```

## 访问
- 页面1: http://localhost:8888/1
- 页面2: http://localhost:8888/2
- 页面3: http://localhost:8888/3

## 特性
- 上下滑动切换页面
- 背景音乐播放
- 一键导航到活动地点
- PC + 移动端自适应

## 文件说明
- `index.html` - 邀请函主页面
- `server.py` - HTTP服务器
- `bgm.mp3` - 背景音乐
